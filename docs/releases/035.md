## Scope

- Replace Provider proxy environment-variable selection with Sing-box outbound nodes.
- Discover supported Sing-box HTTP, SOCKS, and mixed inbound nodes from the server configuration.
- Check every discovered node against the Provider Base URL before allowing node selection.
- Allow multiple selected nodes, ordered by measured connectivity latency, with proxy failover and direct-connection fallback.
- Remove the obsolete `FETCHGITHUB_PROXY_URL` configuration from active setup documentation and schema usage.
