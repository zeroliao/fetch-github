## 目标

- 为 AI Provider 增加可配置冷却时间和冷却异常类型。
- 未配置为冷却的异常进入 `error` 手动恢复状态。
- 冷却到期后先执行最小真实检测，检测成功才恢复为 `available`。
- 每次模型调用只从 `available` Provider 中按优先级选择。
- Provider 检测模拟真实 Chat/Embedding 业务，同时尽量减少输入 Token。

## 变更范围

- Chat 检测使用最小仓库分析请求，并校验生产结构化输出 Schema。
- Embedding 检测使用单条最小输入，校验向量数量和维度。
- 扫描、自然语言发现和语义搜索统一使用到期探针恢复后的 Provider 选择器。
- PostgreSQL 与 JSON fallback 均不在列表读取时直接清除冷却状态。
