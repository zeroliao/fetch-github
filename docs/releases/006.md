## 变更内容

- 新增扫描失败分类与 secret 脱敏，覆盖 GitHub、AI provider、网络、超时、限流和数据库错误。
- 扫描阶段异常会将任务持久化为 `failed`，并记录 `error_code`、`error_message`、`error_resolution`。
- 为旧数据库幂等增加 `discovery_jobs.error_code` 和 `discovery_jobs.error_resolution` nullable 字段。
- 扫描任务页显示错误详情，并在活动任务存在时每 5 秒刷新任务与队列状态。
- 调整 dashboard 导航、发现工作区、移动端布局、键盘交互与视觉层级。
- 将本地凭据文件 `key.json` 加入忽略规则，不提交真实 token。

## 风险与回滚

- 风险：worker 异常语义由无限重试改为任务失败，需要用户修复配置后恢复任务；dashboard 布局改动影响多个主页面；部署包含数据库 schema 追加字段。
- 回滚目标：v005；新增 nullable 字段可保留，应用回滚不需要执行破坏性数据库回滚。
- 数据库备份：部署前从服务器 `.env.local` 安全读取 `DATABASE_URL` 并执行 `pg_dump`；不得输出连接串或凭据。
