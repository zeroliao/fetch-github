## 目标

- 简化发现策略配置，移除运行时数量、Top K、最大运行分钟和具体模型绑定。
- 按规范化 GitHub 仓库地址去重，`processed/skipped` 终态跳过，`failed/exception` 可重试。
- 根据实时可用内存动态批处理，持续扫描并支持 checkpoint 分页。
- 增加 Provider priority、reasoning effort、不可用状态、恢复操作和同类型模型轮换。
- 将推荐喜好、机会资格、机会阶段拆分为独立状态轴。

## 变更内容

- 新增 `repo_processing`、`scan_provider_states`、`provider_health_events` 和 AI Provider 健康字段。
- Provider 按优先级自动选择；连续 3 次 JSON parse/schema 失败后轮换，模型池耗尽进入 `exception`。
- 401/403、429、API Key 缺失、网络/超时、5xx、参数不兼容单独分类，不计入解析失败次数。
- AI Provider 删除改为软删除，保留历史外键数据。
- GitHub Search 按每页 100 条持续分页至结果结束或 1000 条上游边界。
- 推荐不设数量上限，默认综合分降序；增加 `pending` 喜好操作。
- 更新 dashboard、数据库 schema、技术设计、MVP、本地配置和项目 Agent 规则。
- 新增 Cloudflare Access SSH 辅助脚本；登录态过期时可重新授权并自动重试一次，且不输出 JWT。
