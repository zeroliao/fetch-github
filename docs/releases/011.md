## 目标

- 一个 Provider 组支持配置多个 Chat / Embedding 模型。
- Provider 列表按组展示，模型优先级、启用状态、推理程度和健康轮换按模型生效。
- Chat 模型支持“推理程度：不使用”。
- Provider 支持通过服务器环境变量引用 HTTP/HTTPS/SOCKS5 出口代理，兼容 sub2api sidecar。

## 变更内容

- 新增 `ai_provider_groups` 表，并将历史单模型记录迁移为一组一模型。
- 新增 Provider 组创建、修改、删除和列表 API。
- AI 配置编辑页支持模型增删、模型级优先级和代理环境变量名配置。
- 代理真实 URL 只保存在服务器 `.env.local`，数据库和前端仅保存环境变量名。
- 保留 PostgreSQL 和 JSON fallback 两种存储路径。
